\# Network Reconnaissance



A small TCP port scanner built with Python's standard library.



\## Features

\- Scans common TCP ports

\- Detects open ports

\- Identifies common service names by port number

\- Measures connection times

\- Scans multiple ports concurrently



\## Usage



Run with Python 3:



&#x20;   python network-reconaissance.py



Only scan systems you own or have permission to test!
